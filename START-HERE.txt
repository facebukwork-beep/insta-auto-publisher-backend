INSTA AUTO PUBLISHER v14.0 - DURABLE / RESTART-SAFE BACKEND

IMPORTANT:
- Do NOT change APP_SECRET_KEY.
- v14 blocks NEW scheduling until storage-status says restartSafe=true.
- Existing local/ephemeral jobs that were already erased cannot be recovered by this update.

Recommended Render setup:
1) Create a PostgreSQL database (Neon/Supabase/Render Postgres) and copy DATABASE_URL.
2) Create an S3-compatible public bucket (Cloudflare R2/S3).
3) Add these Render Environment Variables:
   DATABASE_URL
   S3_ENDPOINT
   S3_REGION=auto
   S3_BUCKET
   S3_ACCESS_KEY_ID
   S3_SECRET_ACCESS_KEY
   S3_PUBLIC_BASE_URL
   S3_FORCE_PATH_STYLE=false
   REQUIRE_RESTART_SAFE_STORAGE=true
4) Keep your existing APP_SECRET_KEY exactly unchanged.
5) Deploy v14.
6) Open:
   https://YOUR-BACKEND/api/storage-status
7) Only bulk schedule when it returns:
   "restartSafe": true
   "safeToSchedule": true

Laptop extension and Mobile PWA backend URL do NOT change.
